On behalf of the team and everyone who has contributed, I'm happy to announce that Spring Boot 4.2.0-M2 has been released and is now available from Maven Central. This release includes 141 enhancements, documentation improvements, dependency upgrades, and bug fixes . Notable new features include: SSL bundle support for LDAP, including LDAPS support for the embedded LDAP server.
