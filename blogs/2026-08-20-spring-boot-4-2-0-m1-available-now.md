On behalf of the team and everyone who has contributed, I'm happy to announce that Spring Boot 4.2.0-M1 has been released and is now available from Maven Central. This release includes 113 enhancements, documentation improvements, dependency upgrades, and bug fixes . Notable new features include: AMQP 1.0 support, with RabbitMQ-specific features.
